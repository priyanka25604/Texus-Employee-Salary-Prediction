# Texas Employee Salary Prediction

## 📌 Project Overview
This project focuses on analyzing and predicting employee salaries for the Texas state government using historical payroll data. The goal is to extract meaningful insights from the data and build machine learning models that can help estimate employee compensation and understand salary trends.

---

## 🎯 Problem Statement
The Texas state government requires insights into employee payroll data to:
- Understand salary distributions
- Identify outliers in compensation
- Analyze wage disparities across departments and roles
- Predict employee salaries using machine learning models

---

## 🗂️ Dataset Description
The dataset contains salary information for employees across **113 Texas state government agencies**, collected under the Texas Public Information Act.

### Key Attributes:
- Agency & Agency Name  
- Employee Name (First, Last, MI)  
- Job Class Title  
- Gender, Ethnicity  
- Employment Status & Hire Date  
- Hourly Rate, Hours per Week  
- Monthly & Annual Income  

---

## 🛠️ Tasks Performed
- Data Cleaning & Preprocessing  
- Exploratory Data Analysis (EDA)  
- Salary Outlier Detection  
- Department-wise Wage Disparity Analysis  
- Trend Analysis Over Time  
- Machine Learning Model Development  
- Model Comparison & Best Model Selection  
- Documentation of Challenges & Solutions  

---

## 🤖 Machine Learning Models Used
- Linear Regression  
- Decision Tree Regressor  
- Random Forest Regressor  
- Model evaluation using metrics like RMSE and R²  

---

## 📊 Results & Insights
- Identified salary outliers across agencies  
- Observed wage gaps between managerial and non-managerial roles  
- Analyzed salary trends over time for key departments  
- Selected the best-performing model for salary prediction  

---

## ⚠️ Challenges Faced
- Missing and inconsistent salary data  
- Handling outliers without losing important information  
- Feature selection for better model performance  

Solutions were implemented using appropriate data preprocessing and modeling techniques.
